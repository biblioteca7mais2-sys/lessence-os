☁️ Backup no Google Drive
⚙️ Configuração única — Google OAuth
Para salvar no Drive, você precisa de um Client ID gratuito do Google.
Faça isso uma vez só — leva ~3 minutos:
  1. Acesse console.cloud.google.com
  2. Crie um projeto (ex: lessence-os)
  3. Vá em APIs & Services → Credenciais
  4. Clique + Criar credenciais → ID do cliente OAuth
  5. Tipo: Aplicativo da Web
  6. Em "Origens JavaScript autorizadas", adicione null e http://localhost
  7. Ative a Google Drive API no projeto
  8. Cole o Client ID abaixo
A pasta será criada automaticamente se não existir.
